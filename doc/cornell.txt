===============================================================================
1. INTRODUCTION                                                  *cornell-intro*

cornell.nvim provides a Cornell Notes editing layout for Markdown buffers.

The source Markdown remains the authoritative document. Cornell buffers are
scratch buffers and are written back to the source when content changes or
when the document is saved.

===============================================================================
2. COMMANDS                                                      *cornell-commands*

:Cornell
    Toggle Cornell View.

:CornellOpen
    Open Cornell View.

:CornellClose
    Close Cornell View.

:CornellReview
    Toggle Review mode.

:CornellCheck
    Check Cue/Note QID consistency.

:CornellSummary
    Toggle Summary panel.

===============================================================================
3. MAPPINGS                                                      *cornell-mappings*

<C-l> in Cues
    Focus Notes.

<C-h> in Notes
    Focus Cues.

<CR> in Cues
    Jump to the matching Note.

<CR> in Notes
    Jump to the matching Cue.

<leader>cv
    Toggle Cornell View.

<leader>cq
    Add a question.

<leader>cr
    Toggle Review mode.

<leader>cs
    Toggle Summary.

<C-s>
    Save.

q
    Close Cornell View.

===============================================================================
4. CONFIGURATION                                                   *cornell-config*

Example:

    require("cornell").setup({
      cues_width = 32,
      summary_height = 8,
      content_padding = 4,
      qid_prefix = "Q",
    })

The navigation mappings <C-h> and <C-l> are deliberately buffer-local while
Cornell View is active. Cursor synchronization does not change the current
window, so navigation cannot be cancelled by CursorMoved autocmds.
